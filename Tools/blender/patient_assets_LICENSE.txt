Generated by BuildLogs/patient_textured.py in Blender 5.2 from the following sources:

1. MakeHuman base mesh, morph targets (incl. stomach-pregnant), "default" rig, UV layout
   - via MPFB 2 (MakeHuman Plugin For Blender) v2.0.18, Blender extensions platform (pkg id "mpfb")
   - MakeHuman / MPFB assets: CC0 1.0 (public domain dedication). MPFB code itself is GPL; no code is shipped.
   - https://static.makehumancommunity.org/  /  https://github.com/makehumancommunity/mpfb2

2. MakeHuman system assets pack "makehuman_system_assets_cc0.zip" (CC0 1.0)
   https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip
   Used: skins/young_caucasian_female (albedo, re-toned to a light-brown/olive complexion -> patient_skin.png),
         eyes/high-poly + eyes/materials/brown (-> patient_eye.png),
         eyebrows/eyebrow001 (-> patient_brows.png), eyelashes/eyelashes01 (-> patient_lashes.png),
         hair/ponytail01 (darkened -> patient_hair.png; tail below the nape removed).

3. Gown texture (patient_gown.png): procedurally generated in the script (no third-party content).
4. Gown/cut/cap geometry helpers: BuildLogs/patient_realistic.py (project code).
